# 💪 Shabbir's Fitness

A simple, beginner-friendly fitness web app — no gym knowledge needed. It gives you
a full daily plan to **get lean, build muscle, get stronger, and work toward a 6-pack**
using the equipment you already have.

## What's inside

- **Animated exercise demos** — every exercise has a moving stick-figure simulation so you can *see* the movement.
- **Step-by-step instructions** — how to do it, how many sets, how many reps, how long to rest, how to breathe, plus a beginner tip.
- **A 7-day plan** tailored to you (63 kg, 169 cm) using your dumbbells, pull-up bar, punching bag, skipping rope, and the pool.
- **Built-in timer** — for rest gaps, planks, skipping rounds and boxing rounds.
- **Water tracker** — daily goal based on your bodyweight, with reminders on *when* to drink.
- **Beginner guide** — food for muscle & abs, sleep, recovery, and what results to expect.

Your water count and progress are saved in your browser automatically.

## The weekly plan

| Day | Session |
|-----|---------|
| Monday | Push + Abs (chest, shoulders, arms) |
| Tuesday | Boxing + Cardio (bag, skipping) |
| Wednesday | Legs + Core |
| Thursday | Pull + Abs (back, biceps) |
| Friday | Full-Body Strength |
| Saturday | Swim + Cardio |
| Sunday | Rest & Recover |

Every workout follows the same 4 steps: **Warm-up → Main workout → Abs finisher → Cool-down stretch.**

## How to use it

Just open **`index.html`** in any web browser — phone or computer. That's it. No installation, no internet required.
